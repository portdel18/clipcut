                  Setup & help

                  Where to open this file

                  Open index.html in Chrome or Edge on a computer, or use the project's GitHub Pages address (it also works on phones). App previews, such as the Claude app's file viewer, block map servers and downloads, so the map tool stays blank there.

                  Google Maps key (optional)

                  The map tool works without a key using free imagery. A key only adds Google's own satellite, hybrid, and roadmap tiles, plus Google's address search.

                  1. Open Google Cloud Console and create a project (for example "Clip Studio").
                  2. Go to Billing and link a billing account. Google requires one even when you stay inside the free monthly usage.
                  3. Go to APIs & Services → Library and enable Map Tiles API and Geocoding API.
                  4. Go to APIs & Services → Credentials → Create credentials → API key.
                  5. Edit the key. Under API restrictions, choose Restrict key and tick only Map Tiles API and Geocoding API.
                  6. Under Application restrictions: if you open this file by double-clicking it, leave it at None (files opened from disk send no website address). If you serve it from a website or local server, choose Websites and add that address.
                  7. Set guard rails: in Billing → Budgets & alerts add a small budget alert, and lower the daily request quotas under APIs & Services → Map Tiles API → Quotas.
                  8. Paste the key into Map Zoom → Imagery & 3D and press Save & test.

                  As of October 2026, Google's price list gives 100,000 free 2D map tile requests and 10,000 free geocoding requests per month. An HD zoom uses a few hundred tiles; the counter above the preview keeps a running total.

                  Scroll Zoom

                  Open a PDF or images, then type the words you want to highlight and press Add. Scanned PDFs and images have no searchable text: turn on Draw boxes and drag over the words. Scroll the preview to move through the document; hold Ctrl (⌘ on a Mac) and scroll, or pinch, to zoom. Your documents stay on your computer.

                  Before you publish

                  Google's Map Tiles API policies only allow its imagery in promotional videos of your own app, 30 seconds or less. For news and commentary clips, Google's brand guidelines point to Google Earth Studio, which allows non-commercial, news, and entertainment videos with on-screen credit. Every source's credit is burned into the corner of the video; check each provider's terms for commercial use. This isn't legal advice.
